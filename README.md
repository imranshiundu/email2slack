# email2slack

Forward new incoming IMAP emails to a Slack channel, powered by an incoming-webhook.

## How it works

1. Connects to your mailbox over IMAP (checkbox config via env).
2. Detects **new** messages.
3. For every new message, posts a Slack Block Kit message to the configured webhook (with a "Generated by email2slack" context footer).
4. Optional `channel` override per run.

## Setup

```bash
npm install
# configure IMAP + Slack webhook (env/creds outside this repo)
node cli.js
```

## Library surface

```js
import { postToSlack } from './index.js';

await postToSlack(process.env.SLACK_WEBHOOK_URL, {
  text: 'Subject line here',
  // optional channel override
}, fetch);
```

Payloads are simple Slack Web API blocks: heading + preview + context footer.
Anything failing logs to stderr and does not crash the loop.

## Tests

```bash
npm test
```

## Notes

- Intended for personal/small-team automation, not high-throughput alert systems.
- Keep IMAP and Slack credentials outside the repo (env file not committed).
